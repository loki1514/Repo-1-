1. Platform / Master Users
Users who control the entire Proviyaa ecosystem.
* Master Admin — complete platform control
* Platform Admin — platform configuration and administration
* Platform Operations Manager — operational monitoring
* Product Manager — products, features, releases
* Platform Finance Admin — billing, settlements, revenue
* Platform Support Admin — support and organization assistance
* Security / Compliance Admin — security, audit and compliance
* Data / Analytics Admin — platform analytics
* Design Admin - Website and App UI control 
2. Growth / Sales Users(Only Screens ) 
Users responsible for acquiring and growing merchants.
* Growth Admin
* Sales Manager
* Sales Executive / Sales Agent
* Business Development Executive
* Service Provider Sales User
* Partner Manager
* Reseller
* Affiliate
* Referral Partner
* Commission Manager
* Commission Finance User
These operate primarily through the Growth Panel / Commission Panel.
3. Organization / Merchant Users( Only Screens )

* Organization Owner

* Branch / Location Manager
* Operations Manager
* Finance Manager

* HR / Staff Manager
* Marketing Manager
* Inventory Manager
* Procurement Manager
* Customer Support User
* Analyst / Reporting User
* Staff User
* Viewer

5. Customer / Marketplace Users
Users interacting with One Latur.
* Customer
* Guest Customer
* Registered Customer

6. Delivery / Fulfilment Users
Users operating OneLatur.
* Delivery Admin
* Dispatch Manager
* Delivery Operations Manager
* Zone Manager
* Fleet Manager
* Rider / Delivery Partner
* Pickup Agent
* Fulfilment Staff
* Delivery Support Agent
The Rider operates through the Rider App, while dispatch and delivery operations remain centralized in OneLatur rather than inside the restaurant/store applications.
